## Note on `orders.json`

The committed `orders.json` was generated by `python weather_delay.py --mock`,
which uses `fixtures/mock_weather.json` (New York = Rain, London = Snow) so the
`Delayed` path is visible without a live key. `orders.seed.json` is the
untouched input.

To regenerate it against the **live OpenWeatherMap API**:

```bash
cp orders.seed.json orders.json
python weather_delay.py
```

The only thing this needs is an activated key in `.env`. The logic, concurrency,
error handling and apology generation are identical on both paths - `--mock` only
swaps the HTTP call for a local fixture lookup.
